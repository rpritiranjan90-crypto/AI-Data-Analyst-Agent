# 🚀 AI Data Analyst Agent

An AI-powered Data Analytics application that allows users to upload datasets, analyze them, generate insights, visualize data, and interact using natural language.

## ✅ Completed Features

- FastAPI Backend
- REST APIs
- Swagger UI Documentation
- CSV Upload API
- Read CSV using Pandas
- Dataset Metadata
- GitHub Version Control

## 🛠 Tech Stack

- Python
- FastAPI
- Pandas
- Uvicorn
- Git
- GitHub
