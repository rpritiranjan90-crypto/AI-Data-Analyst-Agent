# Screenshots

Add screenshot images here. Reference them in `README.md`.

## Recommended screenshots to capture

| Filename | Description |
|----------|-------------|
| `dashboard-light.png` | Dashboard with active dataset (light mode) |
| `dashboard-dark.png` | Dashboard with active dataset (dark mode) |
| `upload.png` | Upload page with drag-and-drop zone |
| `cleaning.png` | Auto-clean results panel |
| `visualization.png` | Chart grid with multiple chart types |
| `ml-training.png` | ML model training with metrics |
| `ai-insights.png` | AI insights panel with recommendations |
| `governance.png` | AI governance dashboard with cost metrics |
| `login.png` | Login page with glassmorphism styling |

## Recommended capture settings

- Resolution: 1920×1080
- Browser: Chrome with 100% zoom
- Dark mode screenshots: use browser devtools to switch

## After adding screenshots

1. Update `README.md` to reference the actual files:
   ```markdown
   ![Dashboard](docs/screenshots/dashboard-light.png)
   ```
2. Run `npm run build` to include them in the Vercel deployment
